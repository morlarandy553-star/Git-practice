# Sistema de Gestión de Calificaciones

## Nombre del Proyecto
**git-practice** - Sistema de Gestión de Calificaciones con Arreglos y Vectores

## Descripción
Este proyecto es una aplicación desarrollada en Python para la asignatura **Introducción a la Programación** (Capítulo IX: Arreglos y Vectores). El programa permite almacenar, consultar, procesar y modificar las calificaciones numéricas de un grupo de estudiantes utilizando un vector unidimensional, aplicando ciclos y estructuras condicionales.

## Objetivo
Demostrar el uso y la manipulación práctica de arreglos unidimensionales (vectores), el acceso a elementos mediante sus índices, la modificación de datos, el recorrido de colecciones mediante ciclos iterativos y la aplicación de condicionales para realizar cálculos estadísticos básicos.

## Lenguaje Utilizado
* **Python 3.x**

## Funcionalidades Desarrolladas
1. **Mostrar todas las calificaciones:** Muestra la lista completa de calificaciones asociadas a sus respectivos índices.
2. **Consulta por índice:** Permite acceder a una calificación determinada utilizando su posición en el vector.
3. **Cálculo de promedio:** Calcula la media aritmética general de todas las calificaciones del vector.
4. **Calificación más alta y más baja:** Identifica los valores máximo y mínimo presentes en el arreglo.
5. **Conteo de aprobados y reprobados:** Evalúa cada elemento según un umbral de aprobación (70) y determina cuántos estudiantes aprobaron y cuántos reprobaron.
6. **Modificación de una calificación:** Permite cambiar el valor de un elemento en una posición específica del vector mediante su índice.
7. **Mostrar vector actualizado:** Despliega nuevamente la lista de calificaciones con los cambios reflejados.
